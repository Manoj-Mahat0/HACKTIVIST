# Quick Reference - Boundary Editing

## 🎯 Quick Start

### Create Boundary
1. Open "Create Building" from admin dashboard
2. Tap 4+ points on the map
3. Blue markers appear
4. Polygon forms automatically

### Edit Boundary
1. Click **Edit (✏️)** button in app bar
2. **Drag any marker** to adjust
3. Polygon updates in real-time
4. Click **Close (✕)** when done

### Delete Point
1. **Tap a marker** to open menu
2. Select **"Delete Point"**
3. Confirm deletion
4. Point is removed

### Move Point (Alternative)
1. **Tap a marker** to open menu
2. Select **"Move Point"**
3. Marker turns orange
4. **Tap map** where you want it
5. Point moves to new location

## 🎨 Visual Guide

### Markers
- 🔵 **Blue**: Normal boundary point
- 🟠 **Orange**: Point being edited

### Polygon
- 🔷 **Blue outline**: Building boundary
- 🔷 **Blue fill**: Building area (25% opacity)

### Buttons
- ✏️ **Edit**: Enable drag mode
- ✕ **Close**: Exit edit mode
- ↶ **Undo**: Remove last point
- ✕ **Clear All**: Remove all points

## 📊 Stats

- **Points**: Number of boundary markers
- **Area**: Calculated in m²
- **Updates**: Real-time as you edit

## 💡 Tips

### Best Practices
✅ Use satellite view for accuracy
✅ Zoom in when editing
✅ Drag slowly for precision
✅ Check area after editing
✅ Save when satisfied

### Avoid
❌ Too many points (4-8 is enough)
❌ Overlapping boundaries
❌ Rushing - be accurate
❌ Forgetting to exit edit mode

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Marker won't drag | Enable Edit Mode (✏️) |
| Polygon not updating | Drag marker more |
| Can't add points | Exit Edit Mode first |
| Boundary looks wrong | Use Undo or Clear All |

## 📱 Controls

### Tap
- **Map**: Add new point (normal mode)
- **Marker**: Open options menu
- **Edit (✏️)**: Enable drag mode
- **Close (✕)**: Exit edit mode

### Drag
- **Marker**: Move point (edit mode only)
- **Map**: Pan/scroll

### Pinch
- **Zoom in/out**: Adjust view
